**LCE Network** is a community-driven networking project focused on preserving, enhancing, and expanding **Minecraft Legacy Console Edition**.

We aim to bring these things to Legacy Console Edition:

- Networking features from Playstation Network/XBOX Live
- Secure user to server authentication and actual profiles
- Global Leaderboards to connect everyone in the same eco-system
